# Contributing

Issues and focused pull requests are welcome.

Contributions must:

- preserve the Central Economy as the authority for event activation;
- preserve exact semantic-anchor matching and owned-marker removal;
- avoid generic clearing of Zen Map markers;
- avoid runtime XML parsing;
- avoid old Zellno Event Manager and VanillaPlusPlusMap code;
- avoid redistributed DayZ, Zen Map, ZenModCore or third-party assets;
- document and test behavioral changes.

Do not submit compiled PBOs, signatures, keys, server profiles, logs, Steam IDs,
production coordinates or private hosting data.
