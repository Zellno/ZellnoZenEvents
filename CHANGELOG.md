# Changelog

## 0.1.0

- Added active vanilla-event detection for Helicrash, Military Convoy, Police
  Car, Police Situation, Train, Airplane Crate and dynamic contaminated areas.
- Added permanent contaminated-area markers for Rify and Pavlovo.
- Added deterministic consolidation so each logical occurrence receives one
  marker.
- Added private administrator markers and optional global marker delivery.
- Added persistent per-administrator preferences and global visibility state.
- Added the private `!zze` command namespace.
- Added deterministic source manifest generation and candidate PBO builds.
- Validated full-stack server/client operation with Zen Map, ZenModCore and
  VPPAdminTools.
- Confirmed signature integrity, restart persistence and marker/object parity.
