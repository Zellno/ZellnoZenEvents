# Zellno Zen Events v0.1.0

First public release.

This release tracks active vanilla Chernarus events on Zens Map Enhancement,
supports administrator-only and optional global visibility, persists personal
preferences and consolidates multi-object events into one logical marker.

The release was promoted from the locally homologated `v0.1.0-rc.1` candidate.
Mission-specific generation metadata was removed from the public source; the
detection and marker runtime behavior is unchanged.

See [CHANGELOG.md](CHANGELOG.md) and [TESTING.md](TESTING.md) for the complete
feature and validation record.
