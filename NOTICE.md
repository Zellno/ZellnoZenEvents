# Notices and external dependencies

Zellno Zen Events is an independent project by Zellno / Noob Open Source.

It is designed to depend on, but not redistribute:

- Zens Map Enhancement, Steam Workshop ID `3483440991`, by Zenarchist;
- Zens Core Mod / ZenModCore, Steam Workshop ID `3702420204`, by Zenarchist;
- Community Framework (CF), as required transitively by ZenModCore;
- DayZ and its vanilla game data, by Bohemia Interactive.

No Zen Map or ZenModCore source, texture, icon, model, PBO, signature or key is
included in this repository. Their names appear only to document external
dependencies and the public interfaces required for interoperability.

The old Zellno Event Manager and VanillaPlusPlusMap are not source or runtime
dependencies of this project.
